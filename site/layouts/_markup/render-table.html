{{- /* Draws a table of a Markdown page. The table is a real table: it keeps its normal display, so a browser and a screen reader still know its rows, columns and header cells. A table with display:block can lose this. A table that is wider than the column must scroll sideways. A scroll box around the table does that, so the table itself does not change. The box is
, like the box of a drawing (layouts/_shortcodes/diagram.html): - tabindex="0" makes the box a Tab stop. Then a person who uses only the keyboard can move to the box and scroll it with the arrow keys. Chrome (from version 130) and Firefox give the focus to a box that scrolls even without a tabindex, but Safari does not. So in Safari, without it, the keyboard cannot scroll a wide table that has no link (checked in WebKit 26.4, the engine of Safari 26.4). - A box that takes the focus needs a role and a name, so that a screen reader can say what it is. The role is region, and the name is the name of the table. - So every box is a Tab stop and a landmark, also when its table fits and the box does not scroll. The site has no script, so this file cannot know which boxes scroll on the screen of the reader. The name is on the , as aria-label, and the box has the same name. A screen reader can list the tables and the regions of a page by name, so each name must be different. The name is the header cells, such as "Command, What it does". The role already says "table", so the name does not repeat it. The header cells say what the table is about, and the page needs no extra text for it. These rules choose the words: - An empty header cell is "column N" (N counts from 1), so the position of the other cells is not lost: "column 1, z". - When every header cell is empty, or there is no header, the cells of the first body row are used the same way. - When those are empty too, the name is "Table N" (N is the number of the table in the page). - When an earlier table of the page has the same name, the name gets the number of the table: "Command, What it does (table 2)". The earlier names are in .Page.Store, by the number of the table. A table looks only at the lower numbers, so a second render of the page (another output) does not change the result. The text of a cell is HTML already (Hugo has drawn the bold text, the code and the links of the cell). So it is printed as it is, and it is not escaped again. The name is plain text, in an attribute. So the tags are removed (plainify), the entities are turned back into characters (htmlUnescape), and the attribute escapes the result once. Hugo gives the alignment of each cell (.Alignment: left, center, right, or empty). It becomes a class (align-left, align-center or align-right), and site.css sets the text-align of each class. A class keeps the page free of inline style. The header cells have scope="col". The attributes of a table, such as {.wide}, go on the
. This site does not turn them on today (the setting markup.goldmark.parser.attribute.block), but a page that uses them later would lose them without this line. The name of an attribute is safe (the Markdown parser allows only letters, digits and a few signs), and the value is escaped here. test/sitecheck checks the output of this file in the built site, and test/sitecheck/testdata/tables has the pages that test the rules above. */ -}} {{- $number := add .Ordinal 1 -}} {{- /* The words of the first row that has text: the header row, and when it has none, the first row of the body. */ -}} {{- $words := slice -}} {{- range slice .THead .TBody -}} {{- if and (not $words) . -}} {{- $row := slice -}} {{- $hasText := false -}} {{- range $i, $cell := index . 0 -}} {{- with $cell.Text | plainify | htmlUnescape | strings.TrimSpace -}} {{- $hasText = true -}} {{- $row = $row | append . -}} {{- else -}} {{- $row = $row | append (printf "column %d" (add $i 1)) -}} {{- end -}} {{- end -}} {{- if $hasText -}} {{- $words = $row -}} {{- end -}} {{- end -}} {{- end -}} {{- $label := printf "Table %d" $number -}} {{- if $words -}} {{- $label = delimit $words ", " -}} {{- $base := $label -}} {{- $names := .Page.Store.Get "tableNames" | default dict -}} {{- range $earlier, $name := $names -}} {{- if and (lt (int $earlier) $.Ordinal) (eq $name $base) -}} {{- $label = printf "%s (table %d)" $base $number -}} {{- end -}} {{- end -}} {{- end -}} {{- $_ := .Page.Store.SetInMap "tableNames" (printf "%d" .Ordinal) $label -}}
