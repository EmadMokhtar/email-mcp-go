{{- /* Draws a table of a Markdown page. The table is a real table: it keeps its normal display, so a browser and a screen reader still know its rows, columns and header cells. A table with display:block can lose this. A table that is wider than the column must scroll sideways. A scroll box around the table does that, so the table itself does not change. The box has: - tabindex="0", so a person who uses only the keyboard can focus the box and scroll it with the arrow keys. - role="region" and an aria-label. A box that can take the focus needs a role and a name, or a screen reader says only "group" or nothing. The name of the box is "Table: " and the header cells, such as "Table: Command, What it does". The header cells say what the table is about, and the page needs no extra text for it. The name must be different from the name of every other table of the page, because a screen reader lists the boxes by name. When an earlier table of the page has the same name, the name gets the number of the table: "Table 2: Command, What it does". The earlier names are in .Page.Store, by the number of the table. A table looks only at the lower numbers, so a second render of the page (another output) does not change the result. A table with no header text is named "Table 2" (its number). The text of a cell is HTML already (Hugo has drawn the bold text, the code and the links of the cell). So it is printed as it is, and it is not escaped again. The name is plain text, in an attribute. So the tags are removed (plainify), the entities are turned back into characters (htmlUnescape), and the attribute escapes the result once. Hugo gives the alignment of each cell (.Alignment: left, center, right, or empty). The header cells have scope="col". The attributes of a table, such as {.wide}, go on the . This site does not turn them on today (the setting markup.goldmark.parser.attribute.block), but a page that uses them later would lose them without this line. The name of an attribute is safe (the Markdown parser allows only letters, digits and a few signs), and the value is escaped here. */ -}} {{- $number := add .Ordinal 1 -}} {{- /* The text of the header cells, with no tags and no empty cell. */ -}} {{- $headers := slice -}} {{- with .THead -}} {{- range index . 0 -}} {{- with .Text | plainify | htmlUnescape | strings.TrimSpace -}} {{- $headers = $headers | append . -}} {{- end -}} {{- end -}} {{- end -}} {{- $label := printf "Table %d" $number -}} {{- if $headers -}} {{- $label = printf "Table: %s" (delimit $headers ", ") -}} {{- $names := .Page.Store.Get "tableNames" | default dict -}} {{- range $earlier, $name := $names -}} {{- if and (lt (int $earlier) $.Ordinal) (eq $name $label) -}} {{- $label = printf "Table %d: %s" $number (delimit $headers ", ") -}} {{- end -}} {{- end -}} {{- end -}} {{- $_ := .Page.Store.SetInMap "tableNames" (printf "%d" .Ordinal) $label -}}
