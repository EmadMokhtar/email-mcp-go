Connections

An MCP client that connects over HTTP needs an access token. Give each client its own token, with only the permissions it needs. Permissions add up: the highest one includes all the ones below it. A new token stops working after {{.Data.NewTokenDays}} days. A token with no end date works until you revoke it.
